# SandingBerkas support

Official support and privacy materials for SandingBerkas, a macOS folder comparison and synchronization app.

- [Support and troubleshooting](SUPPORT.md)
- [Privacy policy](PRIVACY.md)
- [Ask for help](https://github.com/ahmadnizar0209/sandingberkas-support/issues)

For help, select **Issues** above and choose **New issue**. Search existing issues first. A GitHub account is required to post. Issues are public: do not include private documents, credentials, personal information or unredacted reports and folder paths.

The static site is in `index.html`, `privacy.html`, and `styles.css`. Enable GitHub Pages from the default branch and repository root. Expected site address after successful publication: https://ahmadnizar0209.github.io/sandingberkas-support/

This repository contains support materials only. The application source code is not published here.
