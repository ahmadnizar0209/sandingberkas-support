# SandingBerkas Support

SandingBerkas compares and synchronizes folders on macOS 14 or later.

## Start a comparison

1. Choose a Left folder and a Right folder using Browse.
2. Choose the comparison criteria. Content hash (T2) compares fingerprints; Byte-exact (T3) compares file bytes.
3. Select Compare and review the results.
4. Build a synchronization plan, review its direction and operations, resolve conflicts, and approve it when ready.

## Folder access and unavailable drives

Reconnect the original drive and select the folder again if permission has expired. SandingBerkas requires access to both selected folders. It will not silently substitute a different drive.

## Recovery and schedules

Review the protection policy before running a plan. Recovery copies may be kept in your destination folder. Maintain an independent backup. In this release, scheduled profiles run while the app is open; keep the app open when schedules are enabled.

## Contact

Select the Issues tab in this repository and choose New issue. Use the bug report form for a reproducible problem, or open a general question.

Include your app version, macOS version and the steps that caused the issue. Describe the result you expected and the result you saw. Issues and attachments are public: do not send private file contents, credentials, personal information or unredacted reports and folder paths.

Read the [privacy policy](PRIVACY.md) for details of local processing and storage.
